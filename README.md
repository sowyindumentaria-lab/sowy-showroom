# Sowy Showroom

Tienda de ropa: catálogo por categorías, ventana de prenda con talle y color, carrito y pedido por WhatsApp. Funciona como web app instalable (PWA). Misma estructura que Pyrox (tienda + panel de servicio), con otro rubro.

- Tienda: `index.html` (lee `catalogo.csv`)
- Panel de servicio: `panel/index.html`
- Servidor local: `python3 server.py` → http://localhost:8811/ y http://localhost:8811/panel/
